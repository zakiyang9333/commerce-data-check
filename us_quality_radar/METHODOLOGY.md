# 美股好公司雷达：第一阶段方法说明（v0.1，2026-11-07）

本雷达只研究企业质量，不构成买卖建议。ROCE 高不等于股票值得买。

## 1. 数据来源
| 优先级 | 来源 | 用途 |
|---|---|---|
| 1 | SEC `companyfacts.zip`（XBRL，来自 10-Q / 10-K 及修正版） | 利润表、资产负债表、现金流 |
| 2 | SEC `submissions.zip` | SIC 行业码、实体类型、申报表格历史 |
| 3 | SEC `company_tickers_exchange.json` | 股票代码与交易所 |

每个数字都保存 XBRL 概念名、期间、申报表格、提交日期、accession 编号和 SEC 原文链接（`audit/CIK##########.json`）。同一期间被多次申报时，取**最近一次提交**的数值（即最新重述值），旧值不使用。缺失一律显示 N/A，不估算。

## 2. 股票库
- 交易所：Nasdaq、NYSE、NYSE American。一家公司一行（按 CIK），多类股（如 BRK-A/BRK-B）合并。
- 只保留普通股代码：去掉 -WS/-WT 认股权证、-U 单位、-R 权利、-P* 优先股，以及 Nasdaq 五位代码末位 W/U/R/Z。
- 排除：ETF/基金/商品信托（只交 N 系列表格，或 SIC 6221/6726，或名称含 ETF/FUND 等）、SPAC（SIC 6770）、名称带“清算”的公司、非经营实体。BDC 多为 SIC 6726，按封闭式基金排除。
- 分组：SIC 6798 = REIT；SIC 6000–6499 与 6700–6799 = 金融；其余 = 普通企业。金融和 REIT 也计算 ROCE，但**不进入普通企业排名**。
- 已知局限：完成合并后仍保留 SIC 6770 的公司会被误排除；名称规则会漏掉少数清算公司。第二阶段补人工复核清单。

## 3. ROCE 主口径（所有公司相同）
- **ROCE = EBIT ÷ 平均已动用资本**
- **已动用资本 CE = 总资产 − 流动负债**（XBRL：Assets − LiabilitiesCurrent，同一日期）
- **平均 CE = （期初 CE + 期末 CE）÷ 2**。TTM 的期初 = 一年前同一季末；年度的期初 = 上一财年末；YTD 的期初 = 本财年初。
- **EBIT 方法 A（主）**：OperatingIncomeLoss，即报表上的持续经营营业利润。
- **EBIT 方法 B（备用，必标记 EBIT_FALLBACK）**：税前持续经营利润 + 利息费用。只在公司没有标注营业利润时使用；它包含投资收益等非经营项目。
- **TTM**：最新财年直接取年报；否则 = 本年累计 + 上一财年 − 上年同期累计；都取不到时用最近四个连续季度相加（Q4 = 全年 − 前三季度），并标记 TTM_FROM_QUARTERS。
- 只发年报（20-F/40-F）的公司，“当前 ROCE”用最新财年，标记 NO_QUARTERLY_XBRL。IFRS 公司用 ifrs-full 对应科目。

第二口径（权益 + 有息负债 − 非经营现金）在第一阶段不进入主面板，避免混用；第二阶段作为交叉核对列加入。

## 4. 四种 ROCE
1. **当前 ROCE**：最新一季 TTM，主筛选指标。
2. **年度 ROCE**：最多 10 个财年，5 年统计用最近 5 年。财年按结束日所在年份命名。
3. **YTD ROCE**：本财年累计 EBIT ÷ 本财年初与季末 CE 的平均。**年化值单独一列**（× 365 ÷ 天数），不与年度 ROCE 混用。
4. **调整后 ROCE**：EBIT 加回减值和重组费用，减去正的资产处置收益，期间与 EBIT 完全相同（同样的 TTM 加减项）。防重复计算规则：有“重组+减值”合并科目时用合并科目，另加商誉减值（准则要求商誉减值单列）；否则减值取“总减值科目”与“商誉+无形+长期资产减值之和”中较大的一个，再加重组费用。某期间未标注的项目按 0 计。资本不调整。另给“剔除商誉资本”的参考 ROCE。调整项逐条列在审计文件中；调整超过 EBIT 20% 标记 LARGE_ADJUSTMENT。Reported ROCE 始终保留。

## 5. 失真防护（第八节）
| 标记 | 规则 | 后果 |
|---|---|---|
| CE_NEGATIVE_OR_ZERO | 期初或期末 CE ≤ 0 | N/M，不排名 |
| CE_NEAR_ZERO | 平均 CE < 平均总资产的 10% | N/M，不排名 |
| NWC_NEGATIVE | 流动资产 < 流动负债 | 提示 |
| GOODWILL_HEAVY | 商誉 > CE 的 40% | 提示 |
| EQUITY_NEGATIVE | 股东权益 < 0（常见于大额回购） | 提示，稳定性评级可降为 D |
| BIG_IMPAIRMENT | TTM 减值 > EBIT 的 10% | 提示 |
| BIG_ACQUISITION | TTM 并购现金支出 > 平均 CE 的 10% | 提示 |
| ONE_OFF_GAIN | 处置收益 > EBIT 的 10% | 不进观察池 |
| LEASE_HEAVY | 经营租赁负债 > CE 的 20% | 提示 |
| CE_JUMP | 期末 CE > 期初 1.5 倍 | 提示（资本投入大增） |
| STALE | 最新期末距今 > 200 天 | 数据质量 C，不进观察池 |
| ROCE_DROP_QOQ | TTM ROCE 比上一季下降 ≥ 5 个百分点 | 提示 |
| 周期高峰 | 需行业数据 | 第二阶段 |

阈值是本项目自定的，改动须记入 CHANGELOG。

## 6. 分级
- 质量档：≥50% 卓越；40–50% 极优秀；30–40% 优秀；20–30% 良好；15–20% 观察；10–15% 一般；<10% 低。
- 稳定性：A = 最近 5 个财年全部 ≥20%；B = 最近 3 年 ≥20% 且趋势斜率为正；C = 当前 ≥30% 但不满足 A/B；D = 当前 ≥30% 但有一次性收益、资本基数异常、大额减值或负权益标记。
- 趋势：可用年度 ROCE 的最小二乘斜率，> +1 个百分点/年为上升，< −1 为下降。
- 数据质量：A = 方法 A、标准 TTM、≥3 年历史；B = 备用 EBIT、季度相加、只有年报或历史混用口径；C = 历史 < 3 年、数据过期或当前值 N/A/N/M。
- 观察池：普通企业、当前 ROCE ≥30%、最近 5 年至少 3 年 ≥20%、无严重标记。

## 7. 日期
每家公司分别记录：财报截止日（period_end）、SEC 提交日（latest_filed，作为发布日期）、本系统数据更新时间（data_updated_utc）。尚未发布 Q3 的公司保留上一期有效数据，不估算。

## 8. 预留扩展
`Company` 对象已加载营收、商誉、权益、租赁、并购现金流；第五阶段的 ROIC/WACC、FCF、CAGR、净负债率、DCF 接口在同一对象上加科目即可。
