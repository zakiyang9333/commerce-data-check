1. 口径（所有公司相同）

ROCE = TTM EBIT ÷ 平均已动用资本；已动用资本 = 总资产 − 流动负债；平均 = （一年前季末 + 本季末）÷ 2。EBIT 主口径为 10-Q/10-K 中的营业利润（OperatingIncomeLoss）；未标注营业利润的公司改用“税前持续经营利润 + 利息费用”，并标记“备用 EBIT 口径”（本次 141 家可排名公司）。TTM = 本年累计 + 上一财年 − 上年同期累计。资本为零或负数、或资本低于总资产 10% 的公司显示 N/M，不排名。缺失一律 N/A，没有任何估算值。完整说明见 GitHub 上的 METHODOLOGY.md。

抽查（已核实）：苹果 FY2025（截至 2025-09-27）营业利润 $133.05B；总资产 $359.241B − 流动负债 $165.631B = 资本 $193.61B；上年末资本 $188.588B；ROCE = 133.05 ÷ 191.099 = 69.6%，与引擎输出一致（来源 accession 0000320193-26-000026）。

6. 已知局限（第二阶段处理）

  • 行业目前只有 SEC 的 SIC 描述，还不是 GICS 一级/二级分类；半导体尚未独立分组。
  • 周期高峰检查需要行业数据，尚未做（存储芯片 SNDK、MU、STX、WDC 当前 ROCE 很高，正是需要这项检查的例子）。
  • 调整后 ROCE 依赖公司在 XBRL 中标注的减值、重组和处置收益科目；未标注的一次性项目无法识别。
  • 没有市值和股价，暂不设规模门槛，名单里有资本只有几百万美元的微型公司。
  • 第二口径（权益 + 有息负债 − 非经营现金）尚未加入交叉核对。
  • 完成合并后仍保留 SIC 6770 的公司会被当作 SPAC 排除；BDC 按封闭式基金排除。
